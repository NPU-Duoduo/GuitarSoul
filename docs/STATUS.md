# 当前状态

源码对应 GuitarSoul 0.15.3 Windows x64 预览版。项目定位为以实时音乐共演为核心、像素猫承载反馈的桌面音乐游戏，自由倾听作为独立模式保留。

已实现的主要路径包括显式输入选择、本地伴奏控制、猫和主界面的共演反馈、和弦草稿及文本保存、排练室昼夜表现。本地版本曾完成安装与卸载验证。此发布候选已在当前开发机独立完成 Release 编译；尚未在干净 Windows 环境启动验证。

和弦评测使用既有公开木吉他录音，不代表失真电吉他或新盲测结果。真实吉他接线、完整共演高光时机、纯净 Windows 异机启动和长期使用仍待验证。当前不能把和弦识别称作成熟核心卖点。

项目所有者已确认图像素材为原创，本项目代码、文档和随仓库提供的图像素材采用 MIT 许可证。第三方依赖遵循各自许可证；视频未包含在此目录。
